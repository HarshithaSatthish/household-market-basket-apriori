Household Market Basket Analysis using Apriori

Interactive Streamlit application that discovers household product combinations with the Apriori algorithm — frequent itemsets, support, confidence, lift, and recommendations.

Deploy / Open Live App (Streamlit Cloud) View source on GitHub
Why not a full app on GitHub Pages? GitHub Pages only hosts static HTML/CSS/JS. This project is a Python Streamlit server app, so the interactive demo runs on Streamlit Community Cloud (free). This Pages site is the project homepage and launch pad.

Technique

Apriori association rule mining with support, confidence, and lift (mlxtend).

Dataset

900 household shopping transactions across 22 everyday products.

Features

KPIs, rules, recommendations, Plotly charts, rule network, viva walkthrough.

Viva core flow

  1. Transactions
  2. Preprocessing
  3. One-Hot Encoding
  4. Apriori
  5. Frequent Itemsets
  6. Association Rules
  7. Support / Confidence / Lift
  8. Recommendations

Run locally

cd household-apriori
pip install -r requirements.txt
streamlit run app.py
